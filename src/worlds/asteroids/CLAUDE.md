# Asteroids — Claude instructions

Atari's Asteroids (1979), the rules kept and the look taken to 2026. Built
2026-09-08 as a one-shot on James's go, from the plan in `tmp/asteroids/plan.md`.
Third of the Retro arcade (Surround, Moon Battle 2075, this) — same architecture:
pure core + sim, three.js glow-line renderer, shell with the attract gate + the
configuration panel + file-backed presets, a silent look-dev page, a
sound-stubbed smoke page. **Draft, "unwired": not in the drift registry until
James has flown it and said ship.** Standing rule from Moon Battle 2075 applies:
a named old game is the FEEL, never the spec — when in doubt the contemporary
choice wins, inside the one constraint (single-weight glowing lines on black).

## Files

- `game-core.js` — ALL rules, pure: no DOM, no timers, no Math.random (seeded
  rng in the state). The torus (H = 750, W follows the window's aspect), the
  ship (rotate / thrust with inertia + the cabinet's brake / wrap / shots without limit /
  hyperspace), rocks (three sizes, four normalised outlines, splits, points),
  waves (4, +2, cap 11), the two saucers (big sprays, small aims better as the
  score climbs), the lurk rule, safe respawn, extra ships, the three played-
  through exits. Exposes `globalThis.AsteroidsCore`. Shared verbatim with the
  sim — keep it pure or the sim lies.
- `render3d.js` — the whole picture, nothing else. Fixed camera straight above
  the plane, the field filling the window exactly; two star layers deep behind;
  rocks as black-filled outlines with a broken crease chord (never through the
  centre — that read as a sliced pie); wrap copies at the seams; the ship a 2036
  dart at 1.2× its hull; strokes fly apart on every break; rings for
  hyperspace / the doorway; bloom + tint.
- `game.js` — the shell: attract gate, fixed-step loop (1/120), input, the
  console, synthesis sound (heartbeat that quickens as the field thins, thrust
  noise, three explosion sizes, two saucer sirens), the configuration panel,
  presets, the exits, `globalThis.ASTEROIDS_DEBUG` for the headless checker.
- Sim: `node tmp/asteroids/sim.mjs` — 2,230 assertions on the real core
  (determinism, the torus, thrust/brake/cap, shots, splits + points, waves, the
  saucers, dying + respawn + game over, hyperspace, extra ships, the lurk rule,
  all three exits, an autopilot that clears wave 1, the field re-fit, geometry).
  RUN IT after touching game-core.js.

## The look-dev harness — use it

`tmp/asteroids/lookdev.html` (served: `http://127.0.0.1:4174/tmp/asteroids/lookdev.html`)
is a **silent** page driving `render3d.js` with the core's autopilot flying and
sliders for every look parameter, plus BREAK / DIE / SAUCER / HULK / OPEN / NEW
buttons (H hides the panel). It is where the picture gets judged before it
flies. Keep it. It surfaces every error and exposes `globalThis.LAB = { scene,
state, params, tick, C, setAuto }` so a checker can drive frames when rAF is
frozen (`LAB.tick(dt)`); native crops go out through `/api/dev-snapshot`
(draw the canvas into a 2-D canvas right after a tick — the GL buffer does not
survive a screenshot).

`tmp/asteroids/smoke.html` is generated by `node tmp/asteroids/make-smoke.mjs`:
the real world page with the shared sound control swapped for a no-op stub, so
the full shell can be loaded in the pane without an AudioContext (house rule:
never load a sound world in the pane). `SMOKE.pump(frames, dtMs)` steps the real
loop on its own clock. **Regenerate it after editing index.html.**

## World-specific rules

- **NO SHOT LIMIT (James, 2026-09-08: "remove the shot restriction. i want to be able to
  shoot as much as I want")**: `shotCap` 0 = unlimited is the default, held fire streams at
  `fireRepeat` 0.12 s; the 1979 four-shot cap is a PLAY dial (NO LIMIT / 4 / 8), never the
  default again. Play storage key moved to v2 so his saved cap of four is gone.
- **The rules are the cabinet's**: large 20 / medium 50 / small 100, big saucer
  200, small saucer 1000 (aimed; its error shrinks to ~2° by 40,000), shots carry the ship's drift, a saucer's shots split rocks for no
  points, a saucer flying into a rock dies for nothing, an extra ship every
  10,000, respawn at the centre only once a 130-unit circle is clear. Tune feel
  through `state.opts` (the PLAY dials write there), not by editing these.
  Hold-to-fire repeats at 0.2 s by default (0 = tap only, the 1979 way) — a
  friendliness, not a rule.
- **The lurk rule is on by default** (the later ROM): a still ship for 12 s
  drains the saucer timer 2.5× and makes the next saucer small.
- **Hyperspace**: 0.7 s gone, 6% chance the jump ends you (dial), a 2 s recharge
  shown as the console's bar. Exits ride on it (below).
- **No camera motion, ever** — no chase, no zoom, no shake. James gets motion
  sick. Death feedback is the strokes drifting apart + a small flash.
- **The start gate**: the game never runs on its own. Boot lands in attract
  (rocks drifting, nobody flying); only START (or Enter) begins a game; game
  over returns to the card. Pause on P / Esc / blur / tab hide; Space resumes.
- **The field is the window**: `Core.resizeField` re-fits the torus's width to
  the window's aspect (1.2–2.4) on resize, keeping everything in proportion.
  A zero-size window at load must never poison the aspect (guarded in the core).
- **The console** is one row of glass panels top centre: score, ships in
  reserve (glyphs), wave, the hyperspace bar, best. Never scatter it to the
  corners; never shrink the labels.
- **The ways out (four, `data-drift`, all found by playing, none labelled):**
  1. THE DERELICT — a dead station that drifts across every third wave or so
     (`state.hulk`, no wrap, rocks pass over it); flying into its lit bay leaves.
  2. THE LONG JUMP — every hyperspace has a growing chance (3% + 5% per jump,
     cap 50%) of landing you somewhere else entirely.
  3. THE HOLLOW ROCK — from wave 2 every wave hides one large rock with a glint
     inside (wave 1: a coin flip). It never counts toward the wave and never
     splits: a shot OPENS it (rings of light inside), and flying through the
     open rock leaves. Closed, it is still a rock.
  4. THE SMUDGE — a static dusty rose-amber blob at the field's left edge
     (Surround's stray-star register: a colour, never a bright one, never moves).
  The core emits `{ type: 'exit', which }`; the shell waits `EXIT_BEAT` then
  clicks the hidden anchor. `opts.exits = 0` removes all three played exits (the
  sim's pure-rules suites run that way).
- **Configuration panel**: PLAY (ships, turn rate, thrust, brake, shots on
  screen, hold-to-fire, saucer cadence, hyperspace risk, lurk, seed, TEXT SIZE)
  + LOOK (13 render dials, file-backed presets via `PUT /api/worlds/asteroids/
  presets` — **saving a preset is telling Claude**). Opening it pauses a live
  game; click-away closes it; `C` toggles it. The whole panel is sized in em
  off `--ui-base × --ui-scale`.

## Renderer notes

- Same line kit as Moon Battle 2075 (copied, not shared — extraction into a
  common vector kit waits until a third sibling needs it): screen-space quads,
  MAX blend, one half-res bloom level, tint in the composite. `pow()` never
  sees a negative; `half` is reserved in GLSL.
- Draw order: stars → the derelict's fill + lines → rock fills + the ship's
  body → every line. A rock's black fill hides the derelict and the stars; the
  derelict's lines sit under the rocks.
- Core coordinates are y-down (screen); world is y-up. `wx()/wy()` convert,
  and every rotation from a core angle uses `(cos a, -sin a)`. Fragments keep
  core coordinates and flip at draw time.
- Wrap copies: `_copies(x, y, r, fn)` draws an object again across the seam
  when it is within `r` of an edge. Everything that can straddle an edge goes
  through it (rocks, ship, bullets, fragments); the saucer only wraps in y.
- The stars are short segments at depth so they draw as dots; longer ones read
  as dashes (seen, fixed).
